# College Placement Management System

## Skill Development Web Application Project

The **College Placement Management System** is a web application developed as part of the Skill Development Lab. The system is designed to simplify and organize the college placement process by providing a platform for students and placement administrators.

The application helps students view placement opportunities, check eligibility, apply for companies, and track their application status. Administrators can manage companies, placement drives, students, and applications.

---

## Project Objectives

- To provide a centralized platform for college placement activities.
- To manage student and company placement information.
- To display available placement opportunities to students.
- To provide eligibility details for placement drives.
- To allow eligible students to apply for companies.
- To track student application and selection status.
- To simplify placement management for administrators.

---

## Main Features

### Student Module

- Student registration and login
- Student profile
- View available placement drives
- View company and job details
- Check placement eligibility
- Apply for eligible placement drives
- Track application status

### Admin Module

- Admin login
- Manage student details
- Add and manage companies
- Create placement drives
- Set eligibility criteria
- View student applications
- Update application status
- Manage placement records
